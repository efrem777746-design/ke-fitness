# KE Fitness

Премиальный адаптивный лендинг для персонального онлайн-сопровождения. Стек: Next.js, TypeScript, Tailwind CSS, Framer Motion и Lucide.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Публикация на Netlify

1. Создайте новый репозиторий на GitHub и загрузите в него **содержимое** этой папки (папки `app` и `public`, а также `package.json`, `next.config.ts` и остальные файлы рядом с ними).
2. Откройте [Netlify](https://app.netlify.com), войдите в аккаунт и выберите **Add new project → Import an existing project**.
3. Подключите GitHub, выберите созданный репозиторий и нажмите **Deploy**. Netlify распознаёт Next.js автоматически — не меняйте предлагаемые настройки сборки.
4. После завершения сборки откройте **Project configuration → Domain management**: там будет публичный адрес вида `https://имя-сайта.netlify.app`. При желании здесь же подключается собственный домен.

Если Netlify попросит указать параметры вручную, используйте: команда сборки `npm run build`, Node.js `20` или новее. Плагин Next.js Netlify должен оставаться включённым автоматически; поле Publish directory оставьте пустым.

## Перед публикацией

- Проверьте ссылки на мессенджеры и социальные сети.
- В `public/images/` находятся три авторские фотографии: `hero.png`, `about.png` и `contact.png`. Их кадрирование настроено непосредственно в `app/page.tsx`.

## Приём заявок

Интерфейс формы уже готов. Для отправки заявок необходимо подключить внешний сервис: в проекте намеренно не добавлены ни ключи, ни аккаунты сторонних сервисов.

Самый простой вариант — создать сценарий в Make или Zapier с Webhook-триггером. Он получает поля `name`, `email`, `messenger`, `goal` и `plan`, затем:

1. Отправляет письмо на `efrem77.7735@gmail.com` через подключённый почтовый сервис.
2. Отправляет сообщение в Telegram через модуль Telegram Bot.
3. Возвращает успешный HTTP-ответ.

Скопируйте URL webhook-сценария в переменную окружения `APPLICATION_WEBHOOK_URL` в настройках Netlify. Для Telegram потребуется создать бота через [@BotFather](https://t.me/BotFather), получить токен бота и узнать ID чата, куда должны приходить уведомления. Эти данные добавляются только в Make/Zapier и Netlify — не в исходный код.

Когда потребуется Stripe, замените обработчик `submitApplication` в `ApplicationForm` на создание Stripe Checkout Session. Сама форма и кнопки выбора тарифа останутся без изменений.
# Google Ads

Сайт загружает один Google tag `AW-18590363162` после согласия на измерение рекламы. Consent Mode v2 работает в базовом режиме. `ad_storage` разрешается при согласии. `ad_user_data`, `ad_personalization` и `analytics_storage` остаются запрещёнными. Выбор можно изменить через «Настройки cookies» внизу страницы.

Событие `conversion` направляется в `AW-18590363162/twaACKiFp78dEJrcyaBF` после успешного ответа `POST /api/lead`. API возвращает случайный идентификатор принятой заявки, который передаётся как `transaction_id`. Поля формы передаются только в существующий обработчик заявок. При отсутствии согласия конверсия не ставится в очередь для последующей отправки.

`ke_contact_click` — отдельное событие в браузерном `dataLayer` после согласия. Параметр `contact_channel` содержит только название канала. Событие не привязано к конверсионной метке или к отдельному сервису отчётности. Контейнер `GTM-KD6HVC2W` и GA4 не загружаются. При переходе на GTM следует заменить прямой Google tag, чтобы сохранить один источник конверсии.

В Google Ads откройте «Цели → Конверсии → Сводка» и найдите существующее действие сайта с указанной меткой. Для оптимизации по заявкам проверьте параметр «Основное» и режим подсчёта «Одна». Убедитесь, что это действие включено в цели кампании. В настройках Google tag проверьте, что для этого действия нет автоматического правила по URL или клику. В разделе расширенных конверсий оставьте сбор предоставленных пользователем данных выключенным.

Для проверки подключите сайт в [Google Tag Assistant](https://tagassistant.google.com/). В новом профиле браузера проверьте, что до согласия и после отказа Google tag не загружается. Разрешите измерение и проверьте команды `consent default` и `consent update`. После согласованной тестовой заявки ожидается ровно один `conversion` с нужной меткой и `transaction_id`. Переход к контакту даёт только `ke_contact_click`, обновление страницы не повторяет `conversion`. Проверку ошибок отправки проводите в тестовой среде с подконтрольным webhook.
